# Axioma — Fruit Fly Connectome Simulation

A complete biological simulation of a fruit fly using the real Princeton connectome (neurons + synaptic connections). Sensors feed through real synapses to motor neurons; behavior is emergent and modulated by circadian, sleep, dopamine, temperature, gut, and environmental fields.

## What's inside

- `fly.py` — Main simulation engine
- `propagate.py` — Signal propagation over the connectome
- `find_sensory.py`, `pair_lookup.py`, `motor_lookup.py` — Neuron lookup / classification helpers
- `analyze_resp.py` — Response analysis

## Requirements

```bash
pip install -r requirements.txt
```

Requires `pandas` and `numpy`.

## Data (Option 2 — GitHub Releases)

The CSV data files are **not tracked by git** (too large / 100 MB/file limit). They are critical for the simulation.

**Download from Releases:**
1. Go to the repo's **Releases** page on GitHub.
2. Download `axioma-data.zip`.
3. Unzip into this repo folder so you have:
   - `neurons.csv`
   - `connections_princeton.csv`
   - `active_neurons.csv`
4. Then run the scripts.

**To create the release zip yourself:**
```bash
python make_release_zip.py
# Then upload axioma-data.zip to GitHub Releases
```

**Files needed at repo root:**
- `neurons.csv`
- `connections_princeton.csv`
- `fly_response.csv` (generated by running `fly.py`)

All scripts use relative paths (`os.path.dirname(...)`) so they work from any clone directory.

## Usage

```bash
python fly.py
python propagate.py
python find_sensory.py
```
